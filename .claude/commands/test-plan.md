For the task just implemented, write in Czech a numbered in-game test for the user:
- prerequisites (which save, which mission, one or two PCs, host/guest role),
- exact steps (CET commands, hotkeys, where to walk),
- expected result for each step,
- which log files to send back if it fails.
Then add the test to `docs/TESTING.md` under the task ID. After the user reports a pass,
check the task in `ROADMAP.md` and record any new game facts in `docs/FINDINGS.md`.
