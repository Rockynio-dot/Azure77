# CP2077 Co-op (pracovní projekt)

Startovní balíček pro Claude Code.

1. Rozbal do prázdné složky a udělej z ní git repozitář (`git init`).
2. Nastav proměnnou prostředí `CP2077_DIR` na složku s hrou.
3. Spusť v ní Claude Code a napiš `/next-task`.

- `CLAUDE.md` – pravidla projektu pro Claude Code
- `ROADMAP.md` – celá mapa: fáze, úkoly s ID, kritéria hotovo, brány
- `.claude/skills/cyberpunk-red4ext-modding/` – znalosti o RED4ext/redscript/CET
- `.claude/commands/` – `/next-task`, `/test-plan`
- `docs/` – šablony FINDINGS, PROTOCOL, KNOWN_ISSUES, TESTING
